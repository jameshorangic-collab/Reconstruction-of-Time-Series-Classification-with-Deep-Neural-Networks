# Time-Series-Classifier-Paper-Reconstruction-

This project is a reconstruion the Multi-Layer Perceptron (MLP) architecture used in the 2016 paper Time Series Classification from Scratch with Deep
Neural Networks: A Strong Baseline. The paper compares the preformance of this MLP framework to other commonly used methods at the time. The point of comparison was the UCR-2015 time series data, which was a commonly used benchmark of the time. The framework itself was a fully connected neural network with three hidden layers, ReLU activation, dropout, a softmax classifier, and the Adadelta optimizer.
